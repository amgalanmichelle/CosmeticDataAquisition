AI Usage Report
What Worked Well

Artificial Intelligence (AI) was used throughout the project to support data acquisition, data preparation and analysis. AI was particularly useful for generating Python code to import and explore the Kaggle cosmetics dataset using the Pandas library. It assisted in identifying appropriate functions for examining the dataset structure, including viewing column names, checking data types, generating summary statistics and identifying missing values.

AI was also valuable during the web scraping stage of the project. It helped generate code using Requests, BeautifulSoup and Regular Expressions to extract product information from the Ulta Beauty website, including product names, brands, ratings and review counts. This significantly reduced the time required to investigate the webpage structure and collect the required data.

In addition, AI assisted with troubleshooting coding errors, interpreting error messages and suggesting alternative approaches when certain scraping methods were unsuccessful. This helped streamline the development process and improve overall efficiency.

What Worked Poorly

Although AI was helpful, some generated code required modification before it could be successfully applied to the project. The structure of both the Kaggle dataset and the Ulta Beauty website differed from AI's assumptions in some cases, resulting in code that required adjustment.

During the web scraping process, several AI-generated regular expression patterns did not initially extract the correct information. The Ulta Beauty website contained a large amount of JavaScript content and metadata, making it difficult to identify the correct fields for brands, product names, ratings and review counts. As a result, manual inspection of the webpage source code was necessary to refine the extraction patterns.

Additionally, AI occasionally suggested solutions that were not fully compatible with the specific dataset structure or project requirements. This highlighted the importance of understanding, testing and validating all AI-generated outputs rather than using them without verification.
